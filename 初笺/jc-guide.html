壹 先把接口配好BEFORE ANYTHING

角初笺不自带模型，用的是你在 设置 · API 里已经填好的那一套 —— baseUrl、密钥、模型名一律复用，不需要再填一遍。

没配的话，落笺、生成动态、聊天回复都会直接提示你，不会静默失败。

如果生成时提示「格式不合法」，多半是模型把 JSON 写坏了。程序会自动清洗、让模型自修、再整轮重试，共三轮；三轮都失败才会报错。换个稳一点的模型通常就好了。
贰 初见 · 怎么把人叫出来THE MEETING

按住中间那枚「落笺」印，等墨迹绕满一整圈再松手 —— 一次会来三位。

卡面不是死板的模板，而是每次现场生成的一份 HTML/CSS/JS 文档：配色、纹样母题、徽记字，都由模型按人物气质给出。

  • 素材库里有图 → 卡面直接用你上传的背景与头像
  • 一张图都没有 → 整张卡用 CSS 现场绘制，月相、细雨、落瓣、烛火、墨晕、霜纹…… 十二种母题按人物气质挑

卡牌可以 左滑换一位、右滑收进存档、点开看全卷。

叁 生成库 · 花过的额度不会白花THE FOUNDRY

只要模型吐出过角色，无条件留档在生成库里 —— 当时随手划走的、没看上的、忘了收的，全都还在。

每一枚都有状态：未处理 / 已收藏 / 划走的。可以随时取回、补进存档、或者直接展开全卷。

只有你自己按「彻底清除」，它才会从列表里消失。

肆 预设 · 让她们长成你要的样子PRESET

十三组维度全部多选：年龄区间、性别、MBTI、性格基调、语言、身份职业、题材风格、时代地域、外貌气质、情感浓度、关系倾向、姓名风格、称呼偏好，另有「明确排除」与「额外要求」两个自由输入框。

凡是勾了的维度，生成时只能在你给的取值里取 —— 这是硬约束，不是参考。

伍 交谈 · 每一条都要你点THE TALK

输入框左边是功能按钮，右边紧挨发送键的是那枚「回」。只有你按下「回」，模型才会被调用，绝不会自己动。

  • 条数：一次回几条由内容自己决定，不设上限、不设下限、不设区间。唯一底线是绝不只回一条。
  • 渐变：连发的一串消息共享同一条长渐变，每条只显示其中一段 —— 发一条看不出来，发四五条才能看出整体过渡。
  • 语音：你点「语音」，写下要说的话，发出去就是语音条；对方点一下才展开文字。时长按内容长度模拟计算。角色也会发语音，频率上限在聊天设置里调，可以调到 0。
  • 翻译：非中文角色每条都会附中文翻译，默认收起，点那枚「译」才展开。
  • 转账 / 送礼物：都会渲染成独立的卡片式消息，角色会对此有反应 —— 收下、推辞、或者追问你为什么。
  • 引用 / 复制 / 删除 / 记为长期记忆：长按任意一条消息。
时间是真的。每次调用都会把当前真实日期、星期、时刻与时段塞进上下文，所以她不会在深夜跟你说早安。时区跟随你在设置里选的那个。
陆 心声 · 她没说出口的那半句INNER VOICE

聊天页顶部常驻一条心声：此刻的情绪、正在做的事、心里那句没发出来的话、对你此刻的态度，还有一条情绪温度。

它和回复在同一次调用里一起生成，生成齐了才一起呈现 —— 不会额外消耗一次额度，也不会出现「话说得亲热、心声却冷冰冰」这种对不上的情况。

点心声条本身可以展开细项。不想看就在聊天设置里关掉。

柒 记忆 · 聊多久都不会失忆MEMORY

三种记录方式：

  • 自动归档：每积累若干条消息（默认 24，可调 10–60），后台静默把这一段压成一条长期记忆。
  • 手动存照：聊天设置 → 记忆 → 「立此存照」，随时给当前进度存一张快照。
  • 钉住：长按某条消息 → 「记为长期记忆」，或在记忆库里钉住任意一条。

拼进上下文时，钉住的全给，其余按时间取最近六条。所以真正重要的事记得钉一下。

捌 心印 · 八枚，不好拿HEART SEAL

必须先缔结任意关系，心印才开始计数。此前一切数值不累计、八印全灰。

积累：每来回 +2、每日首次开口 +8、连续第 n 天 +n（上限 15）、语音 +4、动态互评 +5、缔结或升级关系 +40。
流失：超 72 小时无往来后每 24 小时 −12；解除关系 −60 且印章灰封。

玖 聊天设置 · 背景绝不糊CHAT PREFS

背景是整页完整替换：不加白色遮罩、不做模糊、不压任何一层膜。可读性靠的是文字自身的阴影描边和气泡的半透明层次。

可选全局统一或各角色各自；铺满裁切 / 完整放入 / 平铺三种方式。

字体也在这里：宋体、黑体、楷体、等宽、西文衬线，外加字号与气泡不透明度两个拨盘。

这一页里没有一个浏览器原生控件 —— 开关、滑杆、分段器、图片挑选，全部自绘。
拾 通讯码 · 接到聊天 AppTHE CODE

角色详情页里可以为她签发一枚专属通讯码：LUNA-XXXX-XXXX 加六位验证码。

拿着这组码到「加好友」页验证通过，她就会写进聊天 App 的好友列表 —— 字段和那边原有的结构完全对齐。

已签发但还没认领的，都堆在加好友页的「待认领」里，一键填入。
